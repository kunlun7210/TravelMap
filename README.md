# 足迹地图 · 网页版

基于 [xenon-xys/TravelMap](https://github.com/xenon-xys/TravelMap) 修改。
上游版本：`d670a0c2346b9e59c388c09057299b6ddcde95e4`（2026-09-27）。保留上游 MIT 许可证。

在线使用：[足迹地图](https://kunlun7210.github.io/TravelMap/)

从本地文件切换到在线版时，请先在本地页面导出JSON备份，再在在线版导入。浏览器不会自动转移不同地址的记录。

## 使用

直接用浏览器打开 `index.html`。请将 `index.html`、`style.css`、`app.js`、`poster.js`、`map-data.js` 放在同一目录。
也提供同目录的 `足迹地图-单文件版.html`，单独保存这一份文件即可使用。

1. 在全国图点击省级行政区，进入该省。
2. 点击城市区块，变为绿色表示“去过”；再次点击恢复“未去过”。
3. 点击“全国”返回总览；总览中有足迹的省份呈绿色。
4. 右侧清单可以搜索、点选地区；手机窄屏使用“地区清单”按钮。
5. 右侧清单标题旁的“返回全国”与左上角“全国”作用相同。
6. 全国图左上方可选择“自动／省级／地级市”：自动模式放大至2倍显示地级市区块，缩小后恢复省级总览。选择“省级”可一直保留省级视图，选择“地级市”可直接浏览、点选全国城市。
7. 点击右上角“成就图片”（手机显示“导出”），预览并下载当前省级、市级或省内地图的成就海报。

包含34个省级行政区、393个足迹记录单元，保留原版港澳台数据：
大陆以地级行政区为主，部分省直辖县级单位单列；直辖市、香港和澳门整体记录；台湾按22个市县记录。
这些数字沿用上游数据版本，不代表已逐项核验为最新行政区划。

## 超高清成就图片

海报为3:4竖版，使用原始矢量边界独立排版，不受浏览器窗口大小、地图拖动和缩放位置影响。

- 高清 PNG：3072 × 4096 像素。
- 超高清 PNG：6144 × 8192 像素，约5033万像素。
- SVG 矢量图：可继续放大或用于排版，文字显示取决于接收设备字体。

全国海报跟随当前地图层级：省级图展示到访省份，市级图展示到访城市区块。
省内海报额外注明本省到访进度。所有海报底部均展示全国累计到访的省级行政区、城市／地区数量及总数。
城市数量按393个记录单元计算，包含自治州等地区。

“显示地名”可开关地名：全国市级图只标注到访城市，省内地图标注本省城市，并尽量避让重叠。
生成图片不会改变足迹记录或地图视角。大尺寸PNG受浏览器内存限制，生成失败时可选择较小PNG或SVG。

## 本机保存与备份

记录保存在当前浏览器的 `localStorage` 中，不上传服务器，不需要账号或地图 API Key。
同一地址、同一浏览器刷新后可恢复；更换网址、浏览器或设备不会自动同步。
清除网站数据、使用无痕窗口或浏览器限制存储时，记录可能无法长期保留，请使用“数据备份”。

- 导出 JSON 可备份自己的记录，文件名自动附上本机当天日期，例如 `足迹地图-备份2026-10-22.json`。
- 导入 JSON 会合并记录，并可撤销。
- 支持原版 TravelMap JSON：0至4统一转为“去过”，5为“未去过”。
- 新版使用独立的存储键 `travelmap_visited_v1`，不会覆盖原版 `travelmap_states`。
- 原网站和本地副本属于不同来源，浏览器不会自动转移原网站记录。请先在原网站导出，再在本副本导入。
- 本地文件与 HTTP 网站也可能使用不同存储空间。准备固定使用某个在线地址时，请通过 JSON 迁移。

## 修改内容

- 去除原有封面背景、背景更换功能和安卓下载入口。
- 状态只保留“去过／未去过”，取消六等级和评分。
- 增加省级总览、省内点选、返回全国、地区清单和搜索。
- 增加右侧返回按钮、全国地图缩放切换城市区块，以及手动选择省级／地级市图层。
- 保留本地存储、JSON备份，增加可预览的超高清PNG与SVG成就图片导出。
- 所有脚本、样式和地图几何均在本地，无第三方运行时请求。

## 静态托管

将本目录中的 HTML、JS、CSS 和 LICENSE 上传到 GitHub Pages 等静态托管服务即可；无需构建、后端或安卓版。
本仓库使用 `main` 分支根目录作为 GitHub Pages 发布源；`.nojekyll` 确保静态文件直接发布。

## 地图与来源

城市边界和南海附图沿用上游项目数据。省级总览由同省城市边界合并生成，并处理原始城市边缘量化带来的细小缝隙。
城市路径保持原始数据不变。本项目没有调用高德道路底图或高德用户账户，也不能读取高德 App 内的个人足迹。
地图为原项目的示意数据，供个人足迹记录参考。

文件：`index.html` 页面、`style.css` 样式、`app.js` 交互、`poster.js` 成就图片排版、`map-data.js` 地图数据、`LICENSE` 上游许可。
